# 技术动作检测器 · 阈值与依据（tech_moves.py v2）

按公开动作库复核（REI / Movement Gyms / r-climbharder 技术库）选定的
**姿态 2D 几何可靠**检测器。全部阈值躯干归一化（身位=torso_px），图像 y 向下。

## 相位（持续姿态）

| 动作 | 触发条件 | 阈值依据 |
|---|---|---|
| 侧身 side_on | 肩宽 x 投影 <0.38 进入 / >0.48 退出（滞回）+任一手接触 | 投影崩溃=髋转垂直墙；0.95° 版无手门在动态段误报 |
| 挂脚 heel_hook | 踩点侧踝高于膝 >0.25 身位 + 膝角 <175° | 直腿抬高是高脚不是挂脚，膝弯门区分 |
| 交叉脚 cross_feet | 双踝 x 序相对全片中值翻转 >0.06/0.15 身位（滞回），**无接触门** | 动态换脚时双脚都在动，接触门会漏 |
| 并手 match_hands | 双腕 <0.28 身位 + 双手接触 + 至少一脚接触 + ≥0.4s | 旧 0.35 无脚门把移动中手部交会误报（实测 15→11 且全真） |
| 旗式 flagging | 游离脚 + 外伸 0.5 身位超出支撑基 + 膝直 >150° + **对侧脚踩点** | 双脚离地是动态移动不是旗 |
| 直臂休息 straight_arm | 双肘 >158° + 至少一手挂 | 休息姿势标志 |
| 内扣膝 drop_knee | 膝 x 距中线比髋、踝都近 >0.08 身位 + 膝角 <155° + 同侧脚踩点 | REI 定义：脚尖踩点后膝内滚；v2 新增 |
| 锁臂 lock_off | 支撑肘 **<82°** + 对侧手离点 ≥0.6s | 95° 版把普通单臂伸全部误报（实测 28→16/片） |
| 膝勾 knee_bar | 游离踝贴对侧膝 <0.18 身位 + 高差 <0.15 身位 + ≥0.6s | 0.30 无高差门把跨步经过误报（实测 8→1/片） |

## 事件（瞬时动作）

| 动作 | 触发条件 | 阈值依据 |
|---|---|---|
| 高脚 high_step | 再接触高于对侧膝 >0.12 身位且高于本侧髋 | — |
| 换脚 foot_swap | A 离点→B 在 0.9s 内落于同点 <0.35 身位（A 不回点） | 落点匹配区分换脚与跨步 |
| 交叉手 cross_hands | 移动腕落到对侧腕 x 另一侧 >0.1 身位 | — |
| 压重心 rock_over | 再接触后 CoM 移至踝上方 <0.3 身位 + 上升 ≥0.15 身位 | — |
| 动态跳跃 dyno | 双脚离点 ≥0.25s + CoM 升速 >1.0 身位/s | 留手动态也成立（不要求手离点） |
| 翻上 mantle | 双手低位撑住（腕低于肩线 0.15 身位）+ 双肘 100°→160° + CoM 升 ≥0.25 身位 | 翻上台面标志 |

## 不检测（2D 姿态信息不足，勿硬加）

勾脚尖 toe hook（与挂脚的足向不可分）、侧拉/反扣 gaston（需抓握方向）、
对撑 stemming（需墙面关系）、自行车 bicycle（需夹持对象）。

## 调参纪律

1. 改阈值先全绿 `pytest tests/test_tech_moves.py`；
2. 再在 ≥2 条真实 analysis 上对照口播时间戳复核：口播说「锁臂/换脚」的时刻
   必须检出，且检出总量 ×最小时长不得泛滥；
3. 每个阈值在本表「阈值依据」列留一行来源（为什么是这个数）；
4. `--from-t` 切片检测（基线同段），输出时间为绝对时间。
