# 字幕管线契约（改 caption 相关代码前必读）

SKILL.md §4 的命令与三层纠错概览之外的完整契约。每条都有单测守护
（tests/test_caption_fix.py、test_caption_llm.py）——改行为先改测试。

## 三层纠错（L1/L2/L3）

| 层 | 工具 | 机制 | 边界 |
|---|---|---|---|
| L1 识别 | `transcribe.py --dict` | funasr 热词（硬偏置）/ whisper initial_prompt（软提示） | 热词表取 DICT 术语节，≤400 字符 |
| L2 词典 | `caption_fix.py --dict` | 内置同音词典 + DICT「纠错映射」子串替换 | 时间轴永不动；terms 高亮重算 |
| L3 LLM | `caption_llm.py`（可选） | GLM 同音纠错；key 从 --api-key / $ZHIPUAI_API_KEY / 工作区或技能根 .env 自动读（占位符忽略） | 五道门禁逐条把关，坏条回退原文 |

**五道门禁**（course-subtitles v1.7 契约）：相似度≥0.8（difflib）、
防删除（缩容≤20% 且保留字符≥75%）、拉丁词白名单（禁发明术语）、
语速≤12 字/秒、索引有效。

## 断句与标点（2026-08-29 修订，勿退回）

- **标点全程保留**（course-subtitles「永不删字」）：ct-punc 的逗号/句号
  是真实语音句读。曾有两处删除点都造成过用户可见退化，均已修复：
  1. 微碎句合并曾 `rstrip` 全部标点 → 每个合并边界的真实逗号被剥
     （"到这儿，大包"变"到这儿大包"）。现在：逗号保留、句号降级为
     逗号（既然继续就不算句末）、词中伪迹（这应。|该是）由跨界剥离
     层按 jieba 成词判定精准移除（逗号尾成词即剥；句号尾还需首字
     非虚词，防「了+然=了然」误剥真句尾）。
  2. 断行曾不补尾标点 → 裸行尾读感像丢标点。现在：句末行收「。」、
     续行收「，」。
- **词内绝不拆分**：whisperX/funasr 词元是原子；超长回溯到语气词词元，
  硬切回溯最近逗号；词对边界（时|候、倒|过来）由后合并按成词+间隙
  ≤0.9s 并回，同规则收敛停顿拆出的单词行
- **断句由标点驱动**：句末标点必断；逗号在宽度≥10 且（真停顿≥0.25s
  或宽度≥20）时断；硬上限宽 20/时长 7s；单 token 超限整体保留
- **显示宽度口径**：CJK/全角=1、拉丁=0.5；相邻拉丁词补空格、单字符
  拉丁碎片双向拼回（v|olume）、同词三连口吃折叠（双次保留——真实强调）
- **无标点流（--engine whisper）**：回退停顿合成（≥0.30s→，，
  句末≥0.55s→。）

## 时间轴（asr_align.py）

- funasr 词级时间戳在连续语音上漂 ≈-3s/min（实测 285s 处 -17s）→
  whisperX 同音频作时间轴参考，difflib 文本锚点分段线性 warp
- 锚点绑定匹配块**首尾两端**（只绑首端时中途局部误差 -3.3s）；
  斜率越界锚点丢弃（whisper 中段幻觉循环会把文本绑到错误拷贝）；
  尾锚只在两流内容对齐到末尾时可信（幻觉尾 +13s 曾拉歪整段）
- 双引擎原始词流缓存到 `<out>.raw.json`——调 warp 不用重跑 GPU
- 词映射：拉丁串整体一个时间戳单元、CJK 逐字；数量不等时句内比例
  铺排；jieba 在**去标点核心文本**上分词（原始句文本会切成 247/457
  单字词且标点挂错词）
